🎓 Student Performance Prediction System

📌 Project Description

The Student Performance Prediction System is a Machine Learning-based web application that predicts a student's expected final academic score based on important performance factors.

The application uses a Random Forest Regression algorithm and provides an easy-to-use interface built with Streamlit.

🚀 Features

- Predicts student's final exam score
- Uses Machine Learning for prediction
- Simple and user-friendly interface
- Takes multiple student performance factors as input
- Provides performance classification
- Interactive Streamlit web application

📊 Input Features

The model uses the following factors:

- Daily Study Hours
- Attendance Percentage
- Previous Exam Score
- Assignments Completed

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Random Forest Regression

⚙️ How to Run the Project

1. Clone the repository

git clone https://github.com/yourusername/student-performance-prediction.git

2. Open the project folder

cd student-performance-prediction

3. Install required libraries

pip install -r requirements.txt

4. Run the application

streamlit run app.py

The application will open in your browser.

🧠 Machine Learning Model

The project uses Random Forest Regression to predict the student's final score.

The model learns the relationship between:

- Study hours
- Attendance
- Previous score
- Assignment completion

and the student's final score.

📈 Performance Classification

The predicted score is classified into different performance levels:

Score| Performance
85–100| Excellent 🌟
70–84| Good 👍
50–69| Average 📚
Below 50| Needs Improvement ⚠️

🎯 Objective

The main objective of this project is to demonstrate how Machine Learning can be used to analyze student-related factors and predict academic performance.
